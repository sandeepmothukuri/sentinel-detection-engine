# Postmortems

One file per major incident, named `INC-<number>.md`, written from
[`../workflows/postmortem-template.md`](../workflows/postmortem-template.md) within five business
days of the incident closing.

**This directory is empty because no incident has occurred.** Filling it is a consequence of
operating a SOC, not of writing a repository. The template and the review checklist are here so
that the first real incident has somewhere to land that is better than a chat thread.
